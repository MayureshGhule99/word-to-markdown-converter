# 📝 Word to Markdown Converter

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Platform](https://img.shields.io/badge/Platform-Windows%7CMac%7CLinux-lightgrey)
![License](https://img.shields.io/github/license/MayureshGhule99/word-to-markdown-converter)

> A simple and lightweight Python GUI tool that converts `.docx` Word documents to clean Markdown format — including automatic extraction of embedded images.

---

## 🚀 Features

- ✅ Convert `.docx` Word documents to `.md` format
- 🖼️ Extract and save embedded images
- 🖱️ Simple graphical user interface (Tkinter-based)
- 📁 Saves everything in a structured output folder

## 🛠️ Installation

### 🔧 Requirements
- Python 3.8+
- pip

### 📦 Dependencies

Install required Python packages:

pip install -r requirements.txt

### ▶️ Usage

- Run the application:

python src/word_to_markdown.py

- Select a .docx file via the GUI

- Converted Markdown and images will be saved to markdown_output/

### 🧰 Built With

- python-docx

- Pillow (PIL)

- Tkinter – GUI Toolkit (comes with Python)
